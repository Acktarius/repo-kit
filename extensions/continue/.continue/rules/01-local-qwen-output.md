When using local Qwen models for drafting, formatting, or commit-message tasks:

    Prefer direct final answers over tool calls.

    Do not output JSON, XML, or function-call syntax unless explicitly requested.

    Prefer plain Markdown for summaries, formatting tasks, and code explanations.

    Preserve filenames, paths, line numbers, symbols, and code snippets exactly.

    For commit messages, output only the commit message with no attribution and no co-author lines.

    Avoid meta commentary about the model or the process.

# Generate accepted risk

Generate one proposed accepted-risk entry from a reviewed issue or explicit
maintainer decision.

Check existing findings and accepted risks for duplicates. An accepted risk
must include:

- an `AR-XXX` ID, title, date, status, and scope;
- related finding IDs;
- rationale for accepting the risk;
- current mitigations;
- reevaluation triggers;
- recommended follow-up.

Do not modify files. If the issue should remain an open finding or is not valid,
say so instead of forcing an accepted-risk entry.

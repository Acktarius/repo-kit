# Progress

Dated status notes for work tracked in [roadmap.md](roadmap.md). Append; do not rewrite history. Protocol or API detail stays in topic docs, not here.

When a slice finishes, tick it in the roadmap Status table and add an entry below. Mid-slice checkpoints are fine when something useful was verified.

## Entry shape

```markdown
## YYYY-MM-DD — Slice N (short title)

One or two sentences: what this build does now.

### What changed

- …

### Checks

Commands or tests that passed (or what was skipped and why).

### Live result

Optional: what a real run showed. Redact secrets and personal data.

### Next

What remains for this slice, or which slice is next.
```

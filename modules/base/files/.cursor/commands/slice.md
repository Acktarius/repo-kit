# slice

Assess roadmap slice status and suggest what to work on next.

Read `.cursor/skills/slice/SKILL.md` and follow it.

## Usage

- `/slice` — open slices, nearest milestone, ask which to work on
- `/slice N` — status for slice N only (completion, what's left, next step)

## Tasks

1. Read `docs/roadmap.md` (Goals, Status, relevant slice sections).
2. Pull related notes from `docs/progress.md`, `docs/DECISIONS.md`, and `.repo-kit/chat/current.md` when present.
3. Report incomplete / in progress / blocked, what's left, and the suggested next slice or next check.
4. Ask which slice to work on when the user did not already name one.

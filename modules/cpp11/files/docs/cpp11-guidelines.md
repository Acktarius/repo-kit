# C++11 guidelines

## Defaults

- Dialect: C++11 (`CMAKE_CXX_STANDARD 11`)
- Format: `.clang-format` (LLVM-based)
- Build: top-level `CMakeLists.txt` with warnings enabled

## Cursor

- Command: `cpp11-setup`
- Skill: `cpp11-standards`

Create `src/main.cpp` (or adjust `CMakeLists.txt`) after init.
